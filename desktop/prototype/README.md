# Myrk 白色聊天界面样机

这份可操作的页面回答一个问题：Myrk 的会话、资料与输入区是否符合用户指定的白色聊天布局？它不是已接入模型的正式客户端。

双击同目录的 `index.html`（浏览器页面文件），无需安装依赖。底部「布局预览」切换新会话欢迎页和已有对话页；地址末尾的 `?view=new`、`?view=chat`（页面状态标记）可指定初始画面。预览切换条只属于样机，不是正式软件界面。

- 新会话欢迎页：左侧会话、中央欢迎文字与输入框。
- 已有对话页：右侧用户消息、左侧回答、底部输入框。
- 仅保留本期入口，不加入其他品牌、订阅升级、语音、项目、作品区或模式切换。

可尝试：搜索或切换会话、新建会话、收起侧栏、输入并发送消息、生成中停止、添加或移除演示附件、查看资料摘录、复制回答、打开设置。演示运行时禁止切换会话。

所有回答均为预先准备的演示文字；附件为页面自带虚构资料，不读电脑文件。不联网，不收集连接密码，不写入磁盘，刷新即重置。实际模型连接、文件权限、任务停止、保存重开及桌面打包需要在正式实现中单独验证。
